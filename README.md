# Kubernetes Projects

A collection of Kubernetes projects focused on deploying, configuring, scaling, and managing containerized applications.

The projects cover Kubernetes fundamentals as well as more advanced workloads and production-oriented configurations.

## What You'll Find Here

The projects explore different areas of Kubernetes in which I implemented most or all of the following to the workload:

- Deployments
- Services
- ConfigMaps
- Ingress
- Resource requests and limits
- Horizontal Pod Autoscaling
- Helm
- Kubernetes networking
- Containerized microservices

Projects may vary in scope and are organized separately based on the Kubernetes concept or workflow being demonstrated.

## Technologies

- Kubernetes
- kubectl
- Helm
- Docker
- Git & GitHub
- YAML

Additional Kubernetes tools and AWS services may be used where they are relevant to individual projects.
